# OI Opposite Delta Recovery (MT5)

## Worker

รัน `npx wrangler deploy` จาก `workers/opposite-delta` ด้วยบัญชี Cloudflare ของโปรเจกต์ คัดลอก URL ของ Worker ที่ deploy สำเร็จไปใส่ใน MT5 และ OI Gold Pro

Worker คำนวณเมื่อ MT5 หรือแอปเรียกอ่าน โดยใช้ราคา Gold จาก /mix ของ OI Gold Pro หรือราคา Yahoo GC ที่ต่อปลายด้วย XAUTUSDT ตามชนิดกราฟ ใช้ Delta จาก Binance USDⓈ-M XAUUSDT ช่วง UTC เดียวกัน โดยคำนวณจาก Taker Buy ลบ Taker Sell แล้วล็อกผลแท่งปิดตามกราฟและ TF หากราคาและ Delta มาไม่ครบหรือเวลาไม่ตรงกัน จะไม่มีสัญญาณสดสำหรับแท่งนั้น

เปิด **Opposite Delta Diamonds → สัญญาณส่วนกลางสำหรับ EA** ใส่ Worker URL แล้วกด **ใช้สัญญาณส่วนกลาง** เพื่อดูข้าวหลามตัดจากฟีดเดียวกับ EA ในโหมดนี้ค่า % ปรับขนาดเครื่องหมาย สัญญาณใช้ Delta ที่ไม่เป็นศูนย์และทิศตรงข้ามกับแท่งราคา แอปแสดงประวัติแท่งที่ Worker เคยคำนวณสูงสุด 256 แท่งต่อกราฟและ TF

## MT5

1. คอมไพล์ `OI_Opposite_Delta_Recovery.mq5` ใน MetaEditor และติดบนกราฟที่จะส่งคำสั่ง เช่น XAUUSDc
2. ใน **Tools → Options → Expert Advisors → Allow WebRequest for listed URL** เพิ่มโดเมน Worker
3. ตั้ง `WorkerURL`, `AppChart` (`gold` หรือ `gcy`) และ `SignalTF` ให้ตรงกับกราฟที่ต้องการ เปิด MT5 ค้างไว้บนคอมหรือ VPS
4. ค่าเริ่มต้น `TradeEnabled=false` ใช้ดูสัญญาณบนกราฟ MT5 เปิดเป็น `true` เมื่อต้องการส่งคำสั่งและใช้บัญชี Hedging ทดสอบบนบัญชี Demo ได้ ค่า points อิงจากโบรกเกอร์ เช่น Point = 0.01 ทำให้ 100 points เท่ากับการขยับราคา 1.00

| ค่า | ผล |
| --- | --- |
| `Lots` / `RecoveryLots` | ล็อตเริ่มต้นและล็อตไม้แก้ |
| `SingleTPPoints` | TP รายไม้จากราคาเปิดจริง |
| `RecoveryAtPoints` | ระยะขาดทุนจากราคาเปิดของไม้ใดไม้หนึ่งในฝั่งนั้น ก่อนรอสัญญาณแก้ วัดจาก Bid สำหรับ Buy และ Ask สำหรับ Sell |
| `BasketTPPoints` | ระยะ TP รวมจากราคาเข้าเฉลี่ยถ่วงตามล็อต บวกสำหรับ Buy และลบสำหรับ Sell |
| `MaxSignalAgeSec` | อายุสัญญาณสูงสุดก่อน EA ข้ามสัญญาณ |

ส้ม → Buy และเขียว → Sell ฝั่งใดถึงระยะแก้ ไม้ฝั่งนั้นยังใช้ TP รายไม้จนมีสัญญาณสีเดิมครั้งถัดไปและเปิดไม้แก้สำเร็จ จากนั้นทุกไม้ของ EA ในฝั่งนั้นใช้ TP ร่วมกันและคำนวณใหม่เมื่อเติมไม้แก้ ฝั่งตรงข้ามจัดการชุดของตัวเอง ทุกคำสั่งเปิดส่ง TP พร้อมคำสั่งและไม่ใส่ SL กำไรเป้าหมายเป็นระยะราคาก่อนค่าคอมมิชชันและสวอป
