# OI Opposite Delta Recovery (MT5)

## ส่วนกลาง

1. ใน `workers/opposite-delta/wrangler.toml` ตั้ง `APP_ORIGIN` ให้ตรงกับ origin ของ OI Gold Pro ที่ผู้ส่งเปิดใช้
2. ในโฟลเดอร์ Worker รัน `npx wrangler deploy` ด้วยบัญชี Cloudflare ของโปรเจกต์ แล้วตั้ง secret ด้วย `npx wrangler secret put PUBLISH_TOKEN` ใช้ token สุ่มยาวและเก็บไว้เฉพาะผู้ส่ง
3. เปิด OI Gold Pro ที่กราฟและ TF ที่ต้องการ เช่น Gold M5 เปิด Opposite Delta Diamonds แล้วกด **ส่งสัญญาณให้ EA** ใส่ Worker URL และ Publish token กด **เริ่มส่ง** และเปิดแท็บนี้ค้างไว้ การรีโหลดหน้าต้องเปิดส่งใหม่ ควรใช้ผู้ส่งหนึ่งแท็บต่อกราฟและ TF
4. ระบบส่งค่า Delta, Volume, แหล่งฟีด และสัญญาณของแท่งล่าสุดที่ปิดแล้วเมื่อพบแท่งถัดไป และเมื่อฟีดสดครอบคลุมทั้งแท่ง แท่งที่ข้อมูลมาไม่ครบหรือเก่าเกินหนึ่งนาทีจะถูกข้าม ส่วนกลางเก็บแท่งล่าสุดแยกตามกราฟและ TF

## MT5

1. คอมไพล์ `OI_Opposite_Delta_Recovery.mq5` ใน MetaEditor แล้วติดบนกราฟสัญลักษณ์ที่จะส่งคำสั่ง เช่น XAUUSDc
2. เข้า **Tools → Options → Expert Advisors → Allow WebRequest for listed URL** เพิ่มโดเมน Worker เดียวกับที่ตั้งไว้ในแอป
3. ตั้ง `WorkerURL`, `AppChart` (`gold` หรือ `gcy` ตามกราฟที่ส่ง) และ `SignalTF` ให้ตรงกับแอป ใช้ Magic แยกจาก EA ตัวอื่น
4. ค่าเริ่มต้น `TradeEnabled=false` ใช้ดูสัญญาณบนกราฟ MT5 เปิดเป็น `true` เมื่อต้องการส่งคำสั่งและใช้บัญชี Hedging ควรตรวจสัญญาณและการตั้ง TP ด้วยบัญชี Demo ก่อน ค่า points อิงจากโบรกเกอร์ เช่น ถ้า Point = 0.01 ระยะ 100 points เท่ากับการขยับราคา 1.00
5. ฟีดสดใช้ WebRequest บนกราฟ MT5 แบบปกติ จึงต้องทดสอบผ่าน Demo สำหรับเวอร์ชันนี้

| ค่า | ผล |
| --- | --- |
| `Lots` / `RecoveryLots` | ล็อตเริ่มต้นและล็อตไม้แก้ |
| `SingleTPPoints` | TP รายไม้จากราคาเปิดจริง |
| `RecoveryAtPoints` | ไม้ใดในฝั่งนั้นติดลบถึงระยะนี้จะติดสถานะรอสัญญาณแก้ โดยวัดจาก Bid สำหรับ Buy และ Ask สำหรับ Sell |
| `BasketTPPoints` | ระยะ TP รวมจากราคาเข้าเฉลี่ยถ่วงตามล็อต บวกสำหรับ Buy และลบสำหรับ Sell |
| `MaxSignalAgeSec` | อายุสัญญาณสูงสุดก่อน EA ข้ามสัญญาณ |

ส้ม → Buy และเขียว → Sell ฝั่งใดถึงระยะแก้ ไม้ฝั่งนั้นยังใช้ TP รายไม้จนมีสัญญาณสีเดิมครั้งถัดไปและเปิดไม้แก้สำเร็จ จากนั้นทุกไม้ของ EA ในฝั่งนั้นใช้ TP ร่วมกันที่จะคำนวณใหม่เมื่อเติมไม้แก้เพิ่ม ฝั่งตรงข้ามจัดการชุดของตัวเอง ทุกคำสั่งเปิดส่ง TP พร้อมคำสั่งและไม่ใส่ SL ถ้าราคาถึง TP แล้วระหว่างอัปเดต TP ของโบรกเกอร์ EA จะส่งคำสั่งปิดตามราคาตลาด

กำไรเป้าหมายเป็นระยะราคาเฉลี่ยของชุดก่อนค่าคอมมิชชันและสวอป คำสั่งตลาดที่โบรกเกอร์ปฏิเสธจะแสดงใน Experts และ EA จะรอสัญญาณแท่งใหม่
